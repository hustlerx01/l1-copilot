# Interview talking points: L1-Copilot

1. **Why a local LLM?** SOC logs contain usernames, IPs and hostnames, which are personal and sensitive data. Under DPDP and client contracts they often can't go to a SaaS LLM. Ollama keeps inference on-prem, and the mock fallback means the pipeline never blocks on a GPU.
2. **How I measured it.** I hand-labelled 100 alerts (57 TP / 43 FP), treated TP as the positive class, and computed precision, recall, F1 and MITRE accuracy. For a SOC, **recall matters more**: a missed attack costs more than a wasted ticket. The 1.5B model had 0.07 recall, so it isn't deployable, and I can show that with numbers.
3. **The honest result.** My heuristic baseline (F1 0.91) beat a small LLM (F1 0.18). Lesson: an LLM has to beat a simple baseline before it earns its place. The next steps are an 8B model, few-shot examples, and having the LLM explain while rules decide.
4. **Where both failed.** Hard cases need context that isn't in the alert, such as an internal host brute-forcing (compromised), a low-and-slow attack, or an admin on a travel VPN. The fix is enrichment (asset inventory, VPN egress list, historical counts), not a bigger prompt.
5. **Prompt-injection guardrails.** Log fields like the SSH username are attacker-controlled. I wrap the alert as UNTRUSTED data, strip control characters and braces, allow-list verdicts and MITRE IDs, validate the JSON, and make sure suspected injection can only *raise* a verdict. There's a test for it (`test_prompt_injection_cannot_downgrade`).
6. **The bug I found.** Python's `ipaddress.is_private` returns True for RFC 5737 documentation ranges, so every "external" attacker was being treated as internal (recall 0.47). I replaced it with an explicit RFC 1918 check and added a regression test. Recall went to 0.895.
7. **Sigma and detection engineering.** Three rules (failed-password threshold, invalid-user spray, success-after-failures) mapped to T1110.001/.003 and T1078, with false-positive notes. They link my SSH-Log-Alert idea to the triage layer.
8. **Engineering hygiene.** Seeded, reproducible dataset (CI fails if it drifts), pytest, GitHub Actions, Docker Compose with an optional `llm` profile.
